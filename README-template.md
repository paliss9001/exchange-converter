Exchange Rate Converter

A simple currency exchange rate converter that fetches live exchange rate data and displays historical trends through an interactive chart.

Features
Real-time exchange rates — Currency conversion powered by live data fetched from the Frankfurter API
Data provider — Exchange rate data sourced from the Banco Central do Brasil (BCB), aggregated via the BCB endpoint
Live chart — Interactive historical exchange rate chart to visualize currency trends over time
Multi-currency support — Convert between a wide range of world currencies
Responsive design — Works seamlessly across desktop and mobile devices

How It Works

User selects a base currency and a target currency
The app fetches the latest exchange rates from the Frankfurter API
Conversion is calculated and displayed instantly
Historical rate data is pulled and rendered as a live, interactive chart


Tech Stack

Framework: React 
Data Source: Frankfurter API (https://api.frankfurter.app)
Charting: Chart.js
Styling: CSS, SCSS
Package Manager: vite
